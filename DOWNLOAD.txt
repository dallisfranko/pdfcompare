HOW TO USE PDFOVERLAY (NO CODING)
=================================

Two versions:
1) WEB (easiest)  -> open the "web" folder, double-click Open-PdfOverlay-Web.bat
2) WINDOWS APP    -> download the zip, unzip, double-click PdfOverlay.exe

WEB STEPS
---------
1) Get the "web" folder from GitHub branch cursor/pdf-overlay-poc-6751
2) Double-click Open-PdfOverlay-Web.bat
3) Choose two PDFs in the browser
4) Click Clear everything when done
5) Close the browser tab and the black window

Nothing is uploaded. Original PDFs are not replaced.

WINDOWS APP STEPS
-----------------
1) Open:
   https://github.com/dallisfranko/pdfcompare/blob/cursor/pdf-overlay-poc-6751/releases/PdfOverlay-portable-win-x64.zip
2) Download raw file
3) Extract All
4) Double-click PdfOverlay.exe
